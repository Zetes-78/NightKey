# NightKey

Free two-step sign-in codes for Windows, by [Night Tech Solutions](https://nighttech.solutions/).

## Download

**[Download NightKey for Windows](https://github.com/Zetes-78/NightKey/releases/latest/download/NightKey-Setup.exe)**

Requires Windows 10 (version 2004 or newer) or Windows 11, 64-bit.

## What it does

NightKey shows the 6-digit codes that sites ask for when two-step verification is turned on, the same codes a phone authenticator app shows. Scan a site's setup QR code right off your screen, and copy codes with one click.

Your secret keys are encrypted on your PC and never leave it. NightKey has no accounts, ads or tracking.

Each account's countdown is drawn as a moon: full when a new code appears, waning as it runs out.
